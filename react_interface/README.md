# React Interface

## Requisitos

- Node.js 20.19 ou superior, ou 22.12 ou superior.
- npm (incluído com Node.js).

## Executar em desenvolvimento

A partir da pasta `react_interface`:

```bash
npm install
npm run dev
```

Abra no navegador o endereço local exibido pelo Vite, normalmente
`http://localhost:5173`.
